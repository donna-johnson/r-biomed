Week 1, session 1: before the session

Objects, types, vectors and indexing, tried out in your browser

This page introduces the ideas you will use in the first R session, so that the session itself can concentrate on RStudio. Work through it in order. Every grey code box on this page is live: you can edit the code and press Run Code to see what R does. Nothing needs installing, because R is running inside your web browser.

NoteThe first box takes a few seconds

The first time you run code, your browser has to download and start R. You’ll see a “Loading” message for a few seconds. After that, everything responds immediately.

1. R as a calculator

At its simplest, R works like a calculator. Run the box below, then change the numbers and run it again.

sqrt() is a function: a named piece of code that does a job. You give a function its input inside the brackets, and it gives you back a result.

2. Storing values in objects

Most of the time you will want R to remember a value so you can use it again. You do this by assigning it to an object with the arrow <-, which you can read as “gets”.

Notice that the first line produces no output: it just stores the value. Typing the object’s name on its own asks R to show you what is inside.

Your turn

Store the number 12.5 in an object called crp_value. The second line then doubles it.

NoteHint

Replace the underscores with the number itself. You don’t need quotation marks around numbers.

TipSolution 
crp_value <- 12.5
crp_value * 2

Naming objects

Object names must start with a letter and can’t contain spaces, so patient_age is fine but patient age and 1st_patient are not. Try running the box below to see what R says about a name that breaks the rules.

You’ll meet this error message again in the session. When R says unexpected symbol, it means it couldn’t make sense of the code at all, so it didn’t run any of it.

3. Types of data

R stores different kinds of values in different ways. The class() function tells you what kind of value an object holds.

Numbers are "numeric", text in quotation marks is "character", and TRUE or FALSE is "logical".

Predict before you run. What do you think class("45") will return? Decide, then run it to check.

TipWhy?

The quotation marks make “45” a piece of text, not a number, so R reports "character". This matters more than it looks. If a column of numbers in a spreadsheet contains even one entry such as “High” or “<5”, R will read the whole column as text, and calculations on it will go wrong. You’ll see exactly this happen in the session.

4. Vectors: many values in one object

A vector holds several values of the same type. You create one with c(), which combines values. Many functions work on a whole vector at once.

Real data often has gaps. In R, a missing value is written NA. Run this box and look at the result of mean():

R refuses to guess: if one value is unknown, the mean is unknown too.

Your turn

The mean() function has an argument that tells it to remove missing values before calculating. Fill in the blank so that R calculates the mean of the values it does have. If you’re not sure of the argument’s name, the hint will help.

NoteHint

The argument is called na.rm, short for “NA remove”. It needs to be set to TRUE.

TipSolution 
crp <- c(12.5, 8.1, NA, 5.3, 18.0)
mean(crp, na.rm = TRUE)

5. Picking out values with indexing

Square brackets pick values out of a vector by their position. R starts counting at 1.

Your turn

Use square brackets to return the ages of the second and fourth patients only.

NoteHint

Put a vector of positions inside the square brackets: ages[c(______, ______)].

TipSolution 
ages[c(2, 4)]

Picking values that meet a condition

You can also put a condition inside the square brackets. R checks the condition for every value, producing TRUE or FALSE for each, and keeps only the values where the answer is TRUE.

Your turn

Return only the CRP values that are greater than 10.

NoteHint

The condition goes inside the brackets, and it refers to the vector itself: crp[crp ______].

TipSolution 
crp[crp > 10]

Predict before you run. This vector has a missing value. What do you think ages[ages > 40] will return now?

TipWhy is there an NA?

R can’t know whether a missing age is over 40, so the condition gives NA for that patient, and asking for position NA returns NA. It is easy to miss in a long output, so keep an eye out for it. One fix is ages[which(ages > 40)], which keeps only the positions where the condition is definitely TRUE.

Before you come in

You’re ready for the session if you can:

  • store a value in an object with <- and check its type with class();
  • create a vector with c(), and use na.rm = TRUE when it contains missing values;
  • pick values out of a vector by position, or by a condition, using square brackets.

In the session you will do all of this in RStudio, and learn to use R’s own help pages. Go to the week 1 page to download the student pack before you arrive.
