Week 1, session 2: before the session

Tibbles, the pipe and a first plot, tried out in your browser

In session 2 you’ll start using the tidyverse, the family of R packages we use for the rest of the module. This page lets you try its three most important ideas in your browser before you meet them in RStudio: tables of data (tibbles), the pipe |>, and plotting with ggplot2.

NoteThis page takes a little longer to start

As well as starting R, your browser needs to download the dplyr and ggplot2 packages. Give it up to a minute the first time. The box below loads them; it runs by itself once everything is ready.

1. A table of data

In R, a table of data is called a data frame; the tidyverse’s version is called a tibble. Each column holds one variable, and each row is one observation. R comes with some example datasets, and ToothGrowth is a biological one: the length of odontoblasts (the cells responsible for tooth growth) in 60 guinea pigs, each given one of three doses of vitamin C (0.5, 1 or 2 mg/day) as either orange juice (OJ) or ascorbic acid (VC).

glimpse() shows every column, its type and its first few values:

len and dose are numbers (<dbl>); supp is a factor, R’s way of storing a variable with a fixed set of categories.

2. The pipe and filter()

The pipe, |>, passes whatever is on its left into the function on its right. Read it as “and then”. filter() keeps only the rows that meet a condition:

This reads: “take ToothGrowth, and then keep the rows where dose equals 2”. Notice the two equals signs: == asks “is it equal?”, while a single = is used for naming arguments.

Predict before you run. What do you think happens with a single equals sign?

TipWhat happened?

R stops with an error, and the message suggests you meant ==. This is one of the commonest mistakes in the tidyverse, and one of the few where the error message tells you the fix directly. It’s always worth reading the whole error message.

Your turn

Keep only the guinea pigs that were given orange juice. The supplement is stored in the supp column, and the value you want is "OJ", in quotation marks because it is text.

NoteHint

The condition has the same shape as dose == 2: the column name, two equals signs, then the value: supp == ______.

TipSolution 
ToothGrowth |> filter(supp == "OJ")

3. Choosing columns with select()

filter() chooses rows; select() chooses columns. Steps can be chained with more pipes, each one working on the result of the step before:

Your turn

Show only the len and dose columns, for all 60 animals.

NoteHint

List the column names inside select(), separated by a comma. They don’t need quotation marks.

TipSolution 
ToothGrowth |> select(len, dose)

4. A first plot

ggplot2 builds a plot in layers. You tell it the data, then use aes() to say which columns go on which axis, and then add a geom, the shape used to draw the data, with +:

factor(dose) tells ggplot to treat the three doses as three separate groups rather than as points on a number line.

Your turn

Points are fine, but a boxplot summarises each group more clearly. Replace the blank with the geom that draws boxplots. (Geoms all start geom_, and ggplot2 has one for most kinds of plot you can think of.)

NoteHint

The geom for boxplots is called geom_boxplot.

TipSolution 
ggplot(ToothGrowth, aes(x = factor(dose), y = len)) +
  geom_boxplot()
Warning+ between layers, not |>

The layers of a ggplot are joined with +. Using the pipe there instead is a very common slip, and ggplot’s error message will point it out.

Before you come in

You’re ready for session 2 if you can:

  • explain what a tibble is, and use glimpse() to see its columns and their types;
  • use the pipe |> with filter() to choose rows and select() to choose columns, remembering == for “is equal to”; and
  • make a simple plot with ggplot(), aes() and a geom, joining the layers with +.

In the session you’ll set up the project folder you’ll use for the rest of the module, install and load the tidyverse in RStudio, and import and check a real (if very small and rather messy) dataset.
