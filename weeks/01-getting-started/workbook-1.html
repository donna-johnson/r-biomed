Week 1, session 1: R and RStudio basics

How to use this workbook

This workbook is a Quarto document. You will keep it open in RStudio throughout the session and write your answers straight into it.

  • Ordinary text, like this, is for reading. Type your written answers on the empty line under each Your answer: prompt.
  • Grey boxes that begin with ```{r} are code chunks. Click the green ▶ arrow at the top right of a chunk to run it, or put your cursor inside it and press Ctrl + Shift + Enter (Cmd + Shift + Enter on a Mac). The output appears underneath. Ctrl + Enter runs just the current line.
  • Plain code boxes without {r} show code for you to type into the Console or into an R script. Some activities ask for this on purpose: part of this week is learning what each part of RStudio is for.
  • Save often with Ctrl + S. At the end of the session, click Render to turn the workbook into a web page containing your notes, your code and its output.
