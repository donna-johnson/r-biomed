Week 2: Getting data into shape

From a messy spreadsheet to clear numbers, tables and graphs

Session 1, Tidy data and wrangling. By the end of this session you should be able to:

  • explain what makes a dataset tidy, and why you should never edit the raw data file;
  • find problems in a dataset with glimpse(), summary() and count();
  • tidy column names with clean_names() and rename();
  • rescue numbers stored as text with as.numeric() and parse_number();
  • recode inconsistent categories with case_when(), and make factors with the levels in the order you want;
  • turn missing-value codes into NA, and decide how to handle missing values;
  • remove duplicate rows, and reshape data between wide and long format with pivot_longer(); and
  • check every step, and save a clean copy of the data under a new name.

Session 2, Descriptive statistics and graphs. By the end of this session you should be able to:

  • calculate and interpret the mean, median, standard deviation, interquartile range and standard error, overall and by group;
  • choose between the mean and SD and the median and IQR, and spot when extreme values are distorting a summary;
  • calculate counts and percentages for categorical variables, including within groups;
  • turn a summary into a formatted table for a Word document with flextable;
  • choose a suitable graph for a question, and draw histograms, boxplots, scatter plots, bar charts and line graphs with ggplot2; and
  • label, colour, annotate and save a graph.

Before you start

Download the week 2 student pack and unzip it (instructions below). Then copy its contents into your R_module project folder:

  1. Copy the two workbook files into the top level of R_module, next to your week 1 workbooks.
  2. Open the pack’s data folder, select all the files inside it, and copy them into the data folder in R_module.

Copy the files, not the data folder itself: copying a folder on top of one with the same name can replace it on a Mac, and your week 1 data would be lost. If you’re asked whether to replace Dataset.csv, choose Replace: it’s the same file as last week.

ImportantUnzip the pack before you open anything

The student pack is a zip file: one compressed file that holds several files and folders. You need to extract (unzip) it before RStudio can use what’s inside.

On Windows

  1. Find the zip file you downloaded. It’s usually in your Downloads folder.
  2. Right-click it and choose Extract All….
  3. Click Extract. A new, ordinary folder appears next to the zip, with the same name but without “.zip” on the end.
  4. Open that new folder. You should see the workbook file(s) and a folder called data.

On a Mac

Double-click the zip file. It unzips automatically into a folder with the same name, next to the zip.

Then, in RStudio, choose File › Open File…, go into the extracted folder, and open the workbook.

Don’t open the workbook from inside the zip. Windows lets you look inside a zip file as if it were a folder, but a workbook opened that way can’t reliably save your answers and can’t find its data. If the folder you’re looking at has a zip (zipper) icon, or “.zip” in its name in the address bar, you’re still inside the zip: go back and use Extract All… first.
